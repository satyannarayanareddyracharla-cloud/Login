Code quality improvements for confest.py

1. Keep configuration out of source code
   Store the API key and Programmable Search Engine ID in the
   GOOGLE_API_KEY and GOOGLE_CSE_ID environment variables. Never commit
   credentials to the repository.

2. Keep variable settings in named constants
   The search query, API endpoint, and request timeout are defined as
   constants so they can be changed in one place.

3. Use a finite request timeout
   The API call has a timeout so a stalled network request does not wait
   indefinitely.

4. Handle expected API and network failures clearly
   HTTP errors, connection errors, timeouts, missing credentials, and
   malformed response shapes produce explicit errors instead of being
   hidden or represented as successful empty results.

5. Validate and format API results
   The script checks that the response contains a list of results and prints
   each result's title, link, and snippet in a readable format.

6. Keep the entry point isolated
   The main() function and __main__ guard let the module be imported without
   starting a search automatically.

7. Check API availability and quota
   The Custom Search JSON API is available only to existing customers and
   is scheduled for discontinuation on January 1, 2027. Verify account
   access, quota, and service status before relying on this script.
