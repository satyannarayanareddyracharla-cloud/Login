# Login and Registration Test Automation Prompt

Create browser test automation for the login and registration forms on
[QA Practice Hub](https://qapracticehub.com/#forms).

## Requirements

- Use Python, Pytest, and Playwright with Google Chrome.
- Use the Page Object Model (POM) to separate page locators and interactions
  from test cases.
- Write clean, reusable, and typed code.
- Test successful login with the site's demo credentials (`tester` /
  `password123`).
- Test login with invalid credentials.
- Validate required fields on both forms.
- Test successful registration with sample data.
- Use stable locators and assert the outcome of each interaction.
- Include setup and test execution instructions.
